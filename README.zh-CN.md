## 🔥 为什么选择 X Image Slicer？（核心优势对比）

| 痛点场景 | 传统方式（PS / 网页切图工具） | **X Image Slicer（本扩展）** |
| :--- | :--- | :--- |
| **操作链路** | 打开外部软件 → 切图 → 导出 ZIP → 解压 → 回 X 选图 | **发帖框原生「切图」按钮**，选图或**框内单图原地切分**，一键填入 |
| **切分自由度** | 只能死板等分，宽主体被迫一刀切两半 | **等分 + 自由切分双模式**：点击或键盘**合并 / 拆回**分割线，按原图无损重切，自动记住常用模式 |
| **X 轮播裁边风险** | 发完才发现某张宽切片在 X 时间线被左右砍边 | **X 网页端多图轮播裁边预览**：实时标出会被裁边区域及比例，自由切分支持一键**「调整为不裁边」** |
| **高像素相机原片** | 整图先缩导致细节丢失，或单片超 5MB 被 X 拒传/暴力二压 | **5 亿像素（500MP）直出引擎**：先在原图坐标切分，再按**单片独立控制 ≤4096px & ≤4.5MB** |
| **多图上传顺序** | 手动框选 8～20 个文件极易乱序或漏选 | **自动按左→右顺序注入发帖框**，兼容 4 图 2×2 网格阅读顺序，内置上传就绪与顺序双重核验 |
| **最右侧丢边问题** | 简单整除取整导致最右侧丢失数个像素、接缝错位 | **累计像素边界算法**，余数均匀分配（相差 ≤1px），**100% 覆盖原图全宽** |
| **隐私与安全边界** | 网页工具需上传原图或要求账号授权 Token | **100% 浏览器本地内存运行**，零网络请求、保护草稿文案、**绝不自动点击发布** |

## ✨ 核心卖点

- 🧩 **零跳出原生体验 & 框内单图直接切**：直接嵌入 X 新建帖子工具栏；不仅支持从本地选图，**发帖框内已经粘贴/拖入的单张图片也能一键原地切分替换**，切图窗口内自动屏蔽 X 页面快捷键干扰。
- ✂️ **等分 + 自由切分双模式（合并 / 拆回）**：支持在 `2～20` 份等分基准上切换至「自由切分」，点击或键盘操作任意分割线即可**合并相邻切片 / 沿原分割线拆回 / 清除合并**，始终从原图坐标无损重切，并在本地记住你上次使用的切分模式。
- 📐 **X 网页端轮播裁边提示 & 一键「调整为不裁边」**：基于 X 网页端多图轮播实测规则，在等分与自由切分预览中直观标出左右会被裁掉的区域与约裁比例；自由切分触发裁边时可一键**「调整为不裁边」**，发帖前心中有数。
- 🚀 **5 亿像素（500MP）原片直出引擎**：轻松吞吐中画幅/一亿像素及 4 亿像素摇摇乐大图（实测 `8958×6710` 60MP 城市风光仅需 **0.8 秒**）。坚持**「先在原图坐标切分，再按单片独立计算预算」**，优先保留无损 PNG（含透明通道）或 0.90 高画质 JPEG，绝不预先缩小整张原图毁掉细节。
- 🎯 **5 / 8 / 20 黄金三档 & 真实比例预览**：每次打开默认 `8` 张；内置 **5 / 8 / 20** 推荐档位一键切换，并提供真实几何比例预览（标注每片精确像素与 KB/MB 体积，绝不虚假拉伸）。
- 📝 **草稿完好保护 & 智能完成核验**：完整保留发帖框已写好的文字、Emoji、`#话题` 与 `@提及`；自动排除 X 字数统计进度环干扰，兼容 4 图 2×2 网格阅读顺序核验，确认全部切片上传就绪后**自动关窗**并将状态回写至发帖框。
- 🔒 **100% 纯本地运行 & 手动发布边界**：解码、切图、编码全程在本地内存完成，零后端、零遥测（仅在扩展本地保存「上次切分模式」一项偏好）；严格停在「待发布」状态，最终发布权 100% 交由你亲自掌控。

## 🚀 快速安装（Chrome / Edge）

1. 前往 [Releases](https://github.com/321sssrt-bit/x-image-slicer/releases) 下载最新 `x-image-slicer-v*.zip` 并解压到本地文件夹（开发者也可直接 `git clone` 本仓库）。
2. 浏览器打开扩展管理页面（`chrome://extensions` 或 `edge://extensions`），开启右上角 **「开发者模式」**。
3. 点击 **「加载已解压的扩展程序」**，选择解压后的文件夹（或源码仓库中的 [`extension`](extension) 目录）。
4. 打开 [x.com](https://x.com)，在新建帖子发帖框工具栏点击 **「切图」** 即可。
