# 隐私声明 / Privacy Policy

## 简体中文

**X Image Slicer（X 切图助手）** 是一款 100% 纯本地运行的开源浏览器扩展：

1. **零数据收集**：本扩展不收集、不存储、不传输任何个人身份信息、X（Twitter）账号凭证、Cookie、浏览记录或发帖草稿。
2. **纯本地图像处理**：您选择的本地原图或发帖框内已有图片的解码、左右等分或自由切分、尺寸缩放与格式压缩全程在您浏览器的本地内存中完成，不会上传至任何第三方服务器。
3. **无后台遥测与外链请求**：本扩展不包含任何统计分析代码、广告 SDK、远程脚本或外部服务器通信。切片仅在您主动点击「填入发帖框」后，交由您当前已打开的 `x.com` / `twitter.com` 官方网页上传流程处理，且本扩展绝不会自动点击发布按钮。
4. **仅保存一项本地偏好**：本扩展只在扩展自身的本地存储中保存「上次使用的切分模式（等分 / 自由）」这一项偏好，不保存图片、切片、分割线位置、切片张数或发帖草稿；其余切图参数与临时预览仅存在于当前切图弹窗生命周期的内存中，关闭弹窗后立即释放。

## English

**X Image Slicer** is a 100% client-side, open-source browser extension:

1. **Zero Data Collection**: This extension does not collect, store, or transmit any personally identifiable information, X (Twitter) credentials, cookies, browsing history, or post drafts.
2. **100% Local Image Processing**: Image decoding, `1×N` horizontal slicing (equal or free split), resizing, and format optimization run entirely inside your browser's local memory. Your images are never uploaded to any external or third-party server.
3. **No Telemetry or External Requests**: This extension contains no analytics, tracking scripts, ads, or remote code execution. Generated image slices are passed solely to the official `x.com` / `twitter.com` post composer on your active page only after you explicitly confirm, and the extension never automatically publishes posts.
4. **One Local Preference Only**: The extension stores a single preference, the last-used slicing mode (equal / free), in the extension's own local storage. It never stores images, slices, cut-line positions, slice counts, or post drafts. All other slicing state and previews exist strictly in memory for the current modal session and are released immediately upon closing.
